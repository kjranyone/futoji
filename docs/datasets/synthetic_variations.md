# 学習時に生成する合成データのバリエーション

`tools/train_paper_net_v2.py` の CLI は `--synth-profile diverse` を既定にします。
`./dev.ps1 train` でも自動的にこの条件を使います。画像生成モデルで追加した
0201〜0212の未検証ラベルには依存せず、既存の学習用素材と外周が既知の手続き素材を
組み合わせ、256×256の入力画像と紙面の二値マスクを作ります。

## 追加した変化

| 軸 | 条件 |
|---|---|
| 背景7種類 | 木目、織物、チェック柄、タイル、斑点のある石、薄色の机、電子機器のある机 |
| 手続き紙面7種類 | 本文、楽譜風、雑誌風、帳票、細長いレシート、濃色広告、罫線ノート |
| 配置 | 大きさ・回転・射影・縦横比・枠外へのはみ出し、主な紙の下に他の紙を重ねる |
| 遮蔽 | 小さな紙、ペン・ケーブル・指に似た小物 |
| 紙面内の印刷 | 写真風の階調、濃色の背景、色ブロック、複数段の本文 |
| 照明・撮影 | 窓の縞影、反射、色かぶり、手ぶれ、低解像度化。既存の照明ムラ・ぼけ・ノイズ・JPEG劣化も継続 |
| 負例 | 紙なしの柄付き背景、円形の小物、ケーブル、記事風の表示がある電子機器 |

手続き紙面は紙の境界を学習するためのものです。文字・音符の意味の教師データには
使いません。重なりでは手前の主な1枚を対象とし、遮蔽物に隠れた部分や印刷された
写真・色ブロックも含めて紙全体を正解にします。

## 既定の比率

| オプション | diverse | legacy |
|---|---:|---:|
| `--p-multi` | 0.20 | 0.00 |
| `--p-occluder` | 0.15 | 0.00 |
| `--p-panel` | 0.35 | 0.00 |
| `--p-procedural` | 0.30 | 0.00 |
| `--p-negative` | 0.12 | 0.05 |
| `--p-stack` | 0.00 | 0.00 |
| `--p-clipped` | 0.00 | 0.00 |

全体の15%は既存写真を切り抜き直したサンプル、12%は紙なし、残りは貼り付け合成です。
複数枚・束・はみ出し・遮蔽の比率は貼り付け合成内の排他的な選択確率で、合計1以下にします。
手続き素材の比率は貼り付ける各紙の選択確率です。`diverse` は背景の切り抜きを60%の
確率で試み、それ以外や安全に切り抜けない場合は手続き背景を使います。
数値を明示したオプションはプロファイルの既定値を上書きします。

従来条件の再現には `--synth-profile legacy` を指定します。モデル選択と従来モデルの
比較に使う `fixed_val_set` は、引き続き従来条件・固定シードです。従来条件の画像と
マスク32組が変更前と完全一致することを確認しました。書き出す四隅は90度回転時の
座標ずれを1ピクセル修正しています。

## 確認・保存

```powershell
# 64枚をマスク境界付きで一覧する。プレビュー画像は教師データには使わない。
tools/.venv/Scripts/python tools/train_paper_net_v2.py --preview 64 --seed 1 --preview-out build/synthetic_diverse_preview.jpg

# 画像と正解マスクを256組保存する。保存先が存在すると上書きせず終了する。
tools/.venv/Scripts/python tools/train_paper_net_v2.py --export-synth 256 --seed 1 --synth-out training_data/synthetic_diverse_2026-10-02

# 外部の画像素材なしで教師ラベル・回転・再現性・保存形式をテストする。
tools/.venv/Scripts/python tools/test_synthetic_variations.py -v
./dev.ps1 check
```

保存先には `images/000001.png`、`masks/000001_mask.png`、`manifest.jsonl`、`config.json`
を作ります。画像とマスクは256×256、マスクは背景0・紙面255です。manifestに対象の
有無、四隅、分割を、configに生成シード・確率・元の紙素材と背景素材IDを記録します。
四隅は回転後のキャンバス幅・高さで正規化した値で、はみ出し条件では0〜1を超えます。
マスクが正式なラスタライズ済み教師ラベルです。同じコード・素材・環境・シード・設定で
再生成できます。

保存したバッチは学習側の素材から生成しているため、全件 `split=train` とし、
独立した検証・評価セットには転用しません。現行の学習処理は保存バッチを読み込まず、
同じ設定でその場で生成し続けます。`eval_*` と `quarantine_heldout_dup` は生成処理の
素材にも使いません。

2026-10-02にシード1で256組（紙あり214・紙なし42）を保存し、64枚の一覧を目視確認
しました。生成設定は [synthetic_diverse_2026-10-02.json](synthetic_diverse_2026-10-02.json)
に保管しています。これらの確認はデータ生成の動作確認であり、実写精度の改善を
示すものではありません。モデル採用前に `eval_heldout`、`eval_heldout_rot90`、
`eval_hard`、`eval_web` を使って現行モデルと比較します。

## 条件別の増量バッチ

`tools/expand_synthetic_dataset.py` は、以下の5条件を各1,000組保存します。
群名は重点を置く生成条件を示し、その群の全画像が必ずその条件になるという意味では
ありません。既存写真の切り抜きや負例も各群に混ざります。

| 群 | diverse から上書きする確率 |
|---|---|
| ordinary | 既定値のまま |
| printed_layouts | 手続き紙面0.80、印刷ブロック0.70 |
| overlap_occlusion | 複数枚0.35、束0.30、遮蔽0.30、印刷ブロック0.45 |
| clipped_pages | 複数枚0.05、束0.10、はみ出し0.65、遮蔽0.10、手続き紙面0.50 |
| negative_heavy | 紙なし0.45、手続き紙面0.40 |

```powershell
tools/.venv/Scripts/python tools/expand_synthetic_dataset.py --out training_data/synthetic_expanded_2026-10-02 --per-group 1000 --seed 20261002
```

群ごとに異なるシードを使い、すべての画像とマスクを保存後に検査します。
`summary.json` に実測件数と設定、各群の `preview.jpg` に保存済み画像16枚の
マスク境界付き一覧を記録します。前回の保存セット256組を含めて画像の完全重複を検査します。
同じ保存先への再実行は上書きせず終了します。

このバッチを加えた保存済みの合成データは合計5,256組です。追加群の設定は既定の
学習設定を変更しません。例えば、はみ出しを重点的に学習する場合は以下のように
同じ確率を学習コマンドへ明示します。

```powershell
tools/.venv/Scripts/python tools/train_paper_net_v2.py --synth-profile diverse --p-multi 0.05 --p-stack 0.10 --p-clipped 0.65 --p-occluder 0.10 --p-procedural 0.50 --out build/paper_seg_clipped.onnx
```
