# 紙面検出用の生成データ記録

データセット全体の運用は [DATASET.md](../DATASET.md) を参照してください。このディレクトリには生成バッチごとの条件と確認状況を記録します。

学習時に毎回生成する合成データは [合成バリエーション](synthetic_variations.md) を参照してください。
既定の `diverse` 条件では背景7種類・紙面7種類と、重なり・遮蔽・撮影劣化を組み合わせます。

## 2026-10-02: 条件別の合成データ5,000組

前回の256組に、通常条件・印刷レイアウト・重なりと遮蔽・枠外へのはみ出し・
紙なしを多めに含めた条件の5群を各1,000組追加しました。保存先は
`training_data/synthetic_expanded_2026-10-02/` です。各群に入力画像、二値マスク、
manifest、生成設定、16枚の境界付き一覧を保存しています。

追加分は紙あり4,087組・紙なし913組です。前回分を合わせると合計5,256組
（紙あり4,301組・紙なし955組）になりました。全5,000組の保存後検査を通過し、
各群から16枚ずつ、計80枚の一覧を目視確認しました。

再生成と確認には `tools/expand_synthetic_dataset.py` を使います。
全ペアの画像サイズ、マスクの二値性、対象の有無、四隅、件数を検査し、前回の256組と
追加群の間に画像の完全重複がないことも確認します。条件ごとの実測件数と生成設定は
[synthetic_expanded_2026-10-02.json](synthetic_expanded_2026-10-02.json) に記録します。

学習は引き続きその場で合成する方式です。保存数を増やすだけでは学習で見る画像数は
増えず、学習ステップ数とバッチサイズで決まります。追加の保存セットはすべて学習用で、
条件ごとの画像と教師ラベルの点検に使えます。

## 2026-10-02: 雑誌・複雑な背景

組み込みの imagegen で12枚を生成し、既存の紙面画像200枚に追加しました。

- 画像: `training_data/paper_photos/images/0201.png`〜`0212.png`
- 一覧: `training_data/paper_photos/contact_sheet_diversity_03.jpg`
- データ側の記録: `training_data/paper_photos/diversity_manifest.jsonl`
- Git に保存するプロンプト・メタデータ: [diversity_2026-10-02.jsonl](diversity_2026-10-02.jsonl)

紙あり9枚は、雑誌ページ・見開き・表紙・レシピ・広告・パンフレット・新聞・カタログを対象に、柄付きの布やラグ、散らかった机、斑点模様のカウンター、反射、影、重なり、指による遮蔽を含みます。紙なし3枚は、電子機器、まな板、タブレット上の雑誌表示を含み、紙と似た物体の誤検出を学習するための候補です。

画像を1枚ずつ目視し、12枚の PNG が正常に読み込めることと、プロンプト記録・保存先・ハッシュの対応を確認しました。プロンプトの構図や面積比は生成への指定であり、測定済みの画像ラベルではありません。

紙あり9枚には検証済みの四隅や紙マスクがなく、現在の v2/v4 学習にはまだ入っていません。紙なし3枚は空マスクを対象とします。既存の `gen_teacher_masks.py --all` は負例の記録を参照しないので、教師モデルが抽出した機器などのマスクを紙の正解として使わないでください。マスク・四隅を検証してから学習素材に追加します。

0202は見開き全体、0209は右ページだけ、0208は手前の主なカタログ表紙を対象として記録しています。見開きと1ページのどちらを優先するかは、ラベル付け時に運用と揃えます。追加分の分割は未指定です。検証に使う画像を背景素材として学習に流用することも避けてください。
