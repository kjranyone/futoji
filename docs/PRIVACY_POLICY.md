# Futoji プライバシーポリシー

最終更新日: 2026-10-18

Futoji (以下「本アプリ」) は、音楽教室の紙資料をカメラで撮影し、端末内で整理・閲覧するためのアプリです。
本ポリシーは、本アプリが扱う情報とその取り扱いについて説明します。

## 1. 収集する情報

本アプリは、利用者の個人情報を収集・送信しません。開発者が運営するサーバーはなく、
アプリストアで配信している本アプリはインターネット通信を行いません
(GitHub で配布している版の例外は「5. 更新の確認」を参照)。

本アプリが端末内で扱うデータは次のとおりです。いずれも端末の中にだけ保存されます。

| データ | 用途 | 保存場所 |
|---|---|---|
| カメラで撮影した画像 | 紙資料の切り抜き・補正・表示 | 端末内のアプリ専用領域 |
| ブック名・タグ・ページメモ・手書きメモ | 整理・検索・表示 | 端末内のアプリ専用領域 |
| アプリの設定 | 動作の切り替え | 端末内のアプリ専用領域 |

紙面の自動検出は端末内のモデルで処理し、画像を外部に送ることはありません。

## 2. カメラの利用

カメラ権限は、紙資料を撮影するためだけに使います。撮影した画像は利用者が保存したものだけが端末に残ります。

## 3. 第三者への提供・共有

本アプリが第三者に情報を提供することはありません。
利用者が PDF の「共有」や「バックアップを書き出す」を選んだ場合に限り、利用者が選んだアプリ
(メール・Google ドライブなどのクラウドストレージ) に PDF やバックアップファイル (zip) を渡します。
共有先での取り扱いは、各サービスのポリシーに従います。

「バックアップから復元」では、利用者が選んだ zip ファイルだけを読み込みます。

## 4. 開発者向け機能

設定画面の「開発者向け」にある機能は、既定ではすべてオフです。

- **検出改善用に切り抜き結果を保存**: オンにすると、撮影画像と切り抜きの四隅を端末内のアプリ領域
  (Android: `Android/data/com.kjranyone.futoji/files/training_captures`) に保存します。
  自動で外部へ送信することはありません。
- **紙面検出の自己診断を許可**: 開発用の診断画像があるときだけ端末内で検出を試します。

## 5. 更新の確認 (GitHub で配布している版のみ)

GitHub の Releases ページで配布している Android 版 (APK) に限り、新しいバージョンが出ているかを
確かめるため、起動時 (1 日 1 回まで) と設定画面の「アップデートを確認」を選んだときに
GitHub の API (api.github.com) に最新リリースの情報を問い合わせます。
このとき送るのは通常の通信に含まれる情報 (IP アドレスなど) だけで、撮影した画像やブックのデータは送りません。
GitHub での取り扱いは GitHub のプライバシーポリシーに従います。
アプリストアで配信している版にはこの機能はありません。

## 6. バックアップ

Android の端末バックアップ機能 (Google アカウントへの自動バックアップ) が有効な場合、
アプリのデータが OS の仕組みによってバックアップされることがあります。これは端末の設定で管理されます。

## 7. データの削除

アプリ内でブックやページを削除すると、対応する画像とデータが端末から削除されます。
アプリをアンインストールすると、本アプリのデータはすべて削除されます。

## 8. 子どもの利用

本アプリは個人情報を収集しないため、年齢にかかわらず同じ取り扱いです。

## 9. 改定

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
